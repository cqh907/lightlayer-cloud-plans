## 常见问题

### 海外云服务器需要备案吗？

不需要，也不能备。海外地域全部不支持 ICP 备案，服务器开机就能对外提供服务，代价是不能用于面向国内的经营性网站。

### 国内访问慢怎么办？

跨境链路在晚间高峰会出现丢包和延迟上涨，普通国际线路尤其明显。优先选带优化线路的档位（LightLayer 的 Premium、阿里云的香港节点都属这类），业务对稳定性要求高的话再叠加网络加速产品，别指望默认公网一直稳。

### 流量超了怎么算？

按地域单价计费，各家差距很大。阿里云香港 1 元/GB、新加坡 0.53 元/GB 是公开的参考值。LightLayer 没有公开统一单价，开通账单告警并把超额单价问清楚，是唯一稳妥的做法。

### 停机能不能省钱？

不一定。阿里云海外 ECS 默认停机继续计费，只有部分规格支持停机不收费，而且停机后会释放公网 IP，重启 IP 就变了。LightLayer 的停机政策没有公开说明，第 2 条问题就是问这个。

### 不同机房之间内网通不通？

多数云厂商跨地域内网不通，跨机房通信走公网并产生流量费用。多节点架构要在规划阶段就把这件事定下来，别等上线后才发现。
